# PTR Community Roadmap

**Version:** 0.1

## 1. Environment Roles

### PTR-AI DEV / LAB

ใช้สำหรับ:

- ทดสอบ Discord Bot
- ทดสอบ Webhook และ n8n
- ทดสอบ Agent Prompt และ Output
- ทดสอบคำสั่งใหม่
- ตรวจ Error และ Log

ข้อกำหนด:

- จำกัดสมาชิกเท่าที่จำเป็น
- ห้ามใช้ข้อมูลลูกค้าจริงโดยไม่ปกปิดข้อมูล
- ห้ามเผยแพร่ผลทดลองสู่ Community อัตโนมัติ

### PTR JEW3D COMMUNITY

ใช้สำหรับ:

- ข่าวสารและประกาศ
- ห้องเรียนและความรู้ฟรี
- ถามตอบงานจิวเวลรี่ CAD Rhino MatrixGold และ AI
- Portfolio และ Showcase
- Community Support
- Workshop และกิจกรรม
- Marketplace ในอนาคต

## 3. Access Model

- Visitor: อ่านประกาศและกฎ
- Community Member: ถามตอบและเข้าถึงความรู้ฟรี
- Verified Learner: เข้าร่วม Workshop และส่ง Portfolio
- Professional Member: เข้าถึงเครื่องมือหรือบริการเชิงลึกตามสิทธิ์
- Staff: ดูแลชุมชน ตรวจเนื้อหา และอนุมัติ Agent Output
- Founder: สิทธิ์อนุมัติขั้นสุดท้าย

## 4. Community Safety

- ห้าม Spam, Scam, Malware และการขโมยผลงาน
- ห้ามเผยแพร่ไฟล์ลูกค้าโดยไม่ได้รับอนุญาต
- ต้องให้เครดิตเจ้าของผลงานและแหล่งข้อมูล
- ระบุเมื่อเนื้อหาหรือรูปภาพสร้างด้วย AI ตามความเหมาะสม
- การขายสินค้าและบริการต้องอยู่ในช่องที่กำหนด

## 5. Community Edition

เนื้อหาที่พิจารณาเปิดฟรี:

- คู่มือพื้นฐาน
- Prompt และ Template ที่ไม่เปิดเผยข้อมูลสำคัญของลูกค้า
- Script ขนาดเล็ก
- ตัวอย่างไฟล์ CAD เพื่อการศึกษา
- Checklist ตรวจงาน
- ข่าว AI/Rhino/MatrixGold ที่เกี่ยวข้อง

## 6. Milestones

### Stage 1 — Clean and Organize

กำหนดบทบาท DEV กับ COMMUNITY และจัดช่องให้เข้าใจง่าย

### Stage 2 — Free Learning Hub

เปิดหมวดเรียนฟรีและ Resource Library

### Stage 3 — Portfolio and Support

เพิ่ม Showcase, Portfolio, Peer Help และระบบ Moderator

### Stage 4 — AI Assisted Community

ให้ Agent ช่วยตอบแบบมีแหล่งความรู้และมี Human Review

### Stage 5 — Academy and Marketplace

เชื่อมคอร์ส เครื่องมือ ผู้เชี่ยวชาญ งาน และบริการ โดยรักษาพื้นที่ฟรีไว้เสมอ
