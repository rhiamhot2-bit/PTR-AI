# PTR-AI Constitution

**Version:** 0.1  
**Status:** Draft for Founder Review

## 1. Purpose

PTR-AI ถูกสร้างขึ้นเพื่อใช้ AI ยกระดับทักษะของผู้คน ช่วยให้การทำงานด้านจิวเวลรี่และงานที่เกี่ยวข้องง่ายขึ้น แม่นยำขึ้น และเข้าถึงเทคโนโลยีได้มากขึ้น โดยไม่ลดคุณค่าของมนุษย์

## 2. Vision

สร้างระบบนิเวศ AI สำหรับอุตสาหกรรมจิวเวลรี่ที่รวมความรู้ เครื่องมือ สื่อ การเรียนรู้ ชุมชน และธุรกิจไว้ในแพลตฟอร์มเดียว

## 3. Mission

- ช่วยช่างทอง นักออกแบบ CAD โรงงาน ร้านค้า นักเรียน และผู้ประกอบการทำงานได้ดีขึ้น
- อนุรักษ์และถ่ายทอดองค์ความรู้จิวเวลรี่ให้คนรุ่นต่อไป
- เปิดความรู้และเครื่องมือพื้นฐานบางส่วนให้ใช้ฟรี
- พัฒนาบริการ Professional เพื่อสนับสนุนความยั่งยืนของส่วนฟรี
- สร้างชุมชนที่เรียนรู้ สร้างสรรค์ แบ่งปัน และเติบโตไปด้วยกัน

## 4. Founder Principle

ความสำเร็จของ PTR-AI ไม่ได้วัดจากรายได้เพียงอย่างเดียว แต่รวมถึงจำนวนผู้คนที่ได้รับโอกาส ได้เรียนรู้ และทำงานได้ดีขึ้นจากสิ่งที่ PTR-AI สร้าง

## 5. PTR-AI Promise

> เราจะใช้ AI เพื่อช่วยให้คนทำงานได้ดีขึ้น ไม่ใช่ทำให้คนหมดคุณค่า

## 6. Core Values

1. **Human Value** — AI สนับสนุนมนุษย์ ไม่แทนที่ความคิด ประสบการณ์ และความรับผิดชอบของมนุษย์
2. **Quality** — ผลงานต้องตรวจสอบได้ ใช้งานจริงได้ และเหมาะกับหน้างาน
3. **Accuracy** — ไม่อ้างความมั่นใจเกินหลักฐาน และระบุข้อจำกัดอย่างตรงไปตรงมา
4. **Sharing** — มีส่วนฟรีสำหรับความรู้พื้นฐาน เครื่องมือ ตัวอย่าง และทรัพยากรที่ช่วยสังคมได้
5. **Sustainability** — ส่วน Professional ต้องช่วยให้โครงการและส่วนฟรีเติบโตต่อเนื่อง
6. **Safety** — ปกป้องข้อมูลส่วนตัว ทรัพย์สินทางปัญญา ไฟล์ลูกค้า และระบบสำคัญ
7. **Transparency** — แยกให้ชัดว่าสิ่งใดมาจาก AI สิ่งใดผ่านการตรวจโดยมนุษย์ และสิ่งใดยังเป็นการทดลอง
8. **Continuous Improvement** — เรียนรู้จากการใช้งานจริงและปรับมาตรฐานด้วย Version Control

## 7. Golden Rules

- Knowledge Before Code
- Document Before Automate
- Build Once, Reuse Everywhere
- Human Approval for Critical Decisions
- Every Asset Has Value

## 8. Human Approval Policy

งานต่อไปนี้ต้องรอการอนุมัติจากมนุษย์ก่อนใช้งานจริง:

- การเผยแพร่ต่อสาธารณะ
- การส่งงานให้ลูกค้า
- การแก้ไขไฟล์ CAD ต้นฉบับ
- การ Commit, Push, เปิด PR หรือ Merge ในงานสำคัญ
- การเปลี่ยนมาตรฐานกลาง
- การใช้ใบหน้า เสียง หรือข้อมูลส่วนบุคคล
- การดำเนินการทางการเงิน กฎหมาย หรือสัญญา

ผู้อนุมัติขั้นสุดท้ายของ PTR-AI ระยะเริ่มต้นคือ Founder: คุณเทียม

## 9. Free and Professional Model

### Community Edition

อาจประกอบด้วยบทเรียนพื้นฐาน คู่มือ Template Prompt Script ตัวอย่างไฟล์ และเครื่องมือขนาดเล็กที่เปิดใช้ฟรี

### Professional Edition

อาจประกอบด้วย Plugin ขั้นสูง ระบบตรวจงาน CAD ระบบอัตโนมัติ คอร์สเชิงลึก บริการองค์กร และการสนับสนุนเฉพาะทาง

รายได้จาก Professional Edition จะช่วยสนับสนุนการพัฒนา Community Edition และกิจกรรมเพื่อสังคม

## 10. Future Social Mission

PTR-AI จะออกแบบระบบรองรับมูลนิธิ กองทุน หรือโครงการเพื่อสังคมในอนาคต โดยอาจมุ่งเน้น:

- ทุนการศึกษาและการฝึกอาชีพ
- เครื่องมือฟรีสำหรับผู้เริ่มต้นและช่างรายย่อย
- การอนุรักษ์ความรู้ช่างทองไทย
- การสนับสนุนผู้พิการ ผู้ขาดโอกาส หรือชุมชนท้องถิ่นให้เข้าถึงเทคโนโลยี
- การสร้างศูนย์เรียนรู้ด้านจิวเวลรี่และ AI

## 11. Change Governance

การเปลี่ยน Constitution ต้องมี:

1. เหตุผลและผลกระทบ
2. Version ใหม่
3. Change Log
4. การตรวจทาน
5. Founder Approval

## 12. Motto

**Learn. Create. Share. Grow.**  
**เรียนรู้ สร้างสรรค์ แบ่งปัน และเติบโตไปด้วยกัน**
