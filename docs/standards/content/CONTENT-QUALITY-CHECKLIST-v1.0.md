# CONTENT-QUALITY-CHECKLIST v1.0

ใช้ก่อนส่งให้ผู้ก่อตั้งตรวจและก่อนเผยแพร่

## A. Objective
- [ ] มีเป้าหมายชัดเจน
- [ ] ระบุกลุ่มผู้ชม
- [ ] เลือกแพลตฟอร์มและความยาวเหมาะสม

## B. Accuracy
- [ ] ข้อมูลจิวเวลรี่และ CAD ไม่เกินหลักฐาน
- [ ] ตัวเลขมีหน่วยและไม่ขัดแย้งกัน
- [ ] แยก Concept, Trial และ Production-ready ชัดเจน
- [ ] ระบุจุดที่ต้องให้ช่างหรือผู้เชี่ยวชาญตรวจ
- [ ] ไม่มีข้อมูลลูกค้าหรือข้อมูลลับ

## C. Brand
- [ ] น้ำเสียงสุภาพ จริงใจ เข้าใจง่าย
- [ ] ผู้ก่อตั้งเป็นตัวหลักและ AI เป็นผู้ช่วยเมื่อใช้ Presenter Mode
- [ ] ไม่กล่าวอ้างเกินจริง
- [ ] สอดคล้องกับหลัก AI ช่วยคน ไม่ลดคุณค่าของคน

## D. Script
- [ ] Hook ตรงประเด็น
- [ ] เนื้อหามีลำดับ
- [ ] ประโยคพูดออกเสียงง่าย
- [ ] CTA เหมาะสมและไม่หลอกลวง
- [ ] ไม่มีคำซ้ำหรือเนื้อหาฟุ่มเฟือย

## E. Visual and Assets
- [ ] ใช้สื่อเดิมก่อนสร้างใหม่เมื่อเหมาะสม
- [ ] ได้รับอนุญาตสำหรับใบหน้า เสียง ผลงาน และข้อมูลลูกค้า
- [ ] เครื่องประดับสอดคล้องกับแบบอ้างอิง
- [ ] Thumbnail ไม่ทำให้เข้าใจผิด
- [ ] ระบุไฟล์ต้นฉบับหรือ Asset ID เมื่อมี

## F. Platform
- [ ] อัตราส่วนภาพเหมาะสม
- [ ] ระยะเวลาเหมาะสม
- [ ] Caption และ Hashtag ไม่มากเกินจำเป็น
- [ ] รูปแบบข้อความอ่านได้บนมือถือ

## G. Approval
- [ ] สถานะเป็น `needs_review` หรือ `needs_expert_review`
- [ ] ระบุเหตุผลที่ต้องอนุมัติ
- [ ] ยังไม่เผยแพร่ก่อน Founder Approval

## Stop conditions
หยุดและขอข้อมูลเพิ่มทันทีเมื่อ:
- ขนาด วัสดุ จำนวนพลอย หรือเป้าหมายไม่ชัด
- ต้องใช้หน้าหรือเสียงผู้ก่อตั้งแต่ไม่มีการอนุมัติ
- ต้องใช้ข้อมูลลูกค้าแต่ไม่ทราบสิทธิ์
- มีความเสี่ยงว่างาน CAD หรือข้อมูลผลิตจะถูกเข้าใจว่าอนุมัติแล้ว
